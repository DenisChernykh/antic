# Antic — интерьерный сайт

Адаптивный сайт с интерьерным контентом и визуальными секциями.

## Возможности

- Многостраничная HTML-структура.
- Собственные CSS-стили и JavaScript-интерактивность.
- Локальные изображения и ресурсы.

## Инженерные акценты

- Точность вёрстки и визуальная композиция.
- Организация стилей и адаптивного поведения.
- Самодостаточная статическая публикация сайта.

## Стек

JavaScript, HTML, CSS.

## Просмотр

Откройте `index.html` через локальный HTTP-сервер. Исходники и ресурсы находятся в этом репозитории.
